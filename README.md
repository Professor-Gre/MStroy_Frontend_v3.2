# TreeStore

Тестовое задание для MStroy: реализация хранилища древовидных данных на TypeScript и их интерактивная визуализация на Vue 3 с Composition API.

Исходные требования — в [тестовом задании](<Тестовое задание MStroy Frontend(v3.2).pdf>).

## О проекте

Проект будет демонстрировать работу с иерархией, заданной плоским массивом объектов. Каждый элемент содержит собственный идентификатор `id`, ссылку на родителя `parent` и произвольные дополнительные поля. Идентификаторы могут быть строками или числами, а порядок элементов в массиве не определяет их положение в дереве.

В основе решения — класс `TreeStore`, отвечающий за хранение элементов, поиск связей и изменение структуры дерева. Интерфейс приложения представит эти данные в виде таблицы с раскрываемыми вложенными строками.

Сейчас доступен прототип таблицы AgGrid с данными из [public/items.json](public/items.json), загружаемыми через `fetch`. Группы раскрываются и сворачиваются, нумерация соответствует видимым строкам. Подключение к `TreeStore` и искусственная задержка загрузки — следующие этапы.
