# TreeStore

Тестовое задание для MStroy: реализация хранилища древовидных данных на TypeScript и их интерактивная визуализация на Vue 3 с Composition API.

Исходные требования — в [тестовом задании](<Тестовое задание MStroy Frontend(v3.2).pdf>).

## О проекте

Проект будет демонстрировать работу с иерархией, заданной плоским массивом объектов. Каждый элемент содержит собственный идентификатор `id`, ссылку на родителя `parent` и произвольные дополнительные поля. Идентификаторы могут быть строками или числами, а порядок элементов в массиве не определяет их положение в дереве.

В основе решения — класс `TreeStore`, отвечающий за хранение элементов, поиск связей и изменение структуры дерева. Интерфейс приложения представит эти данные в виде таблицы с раскрываемыми вложенными строками.

Таблица AgGrid получает данные из `TreeStore` через composable [useTreeStore](src/composables/useTreeStore.ts). Исходный JSON из [public/items.json](public/items.json) загружается через `fetch` после искусственной задержки в две секунды и передаётся в изначально пустое хранилище через `setItems`. Во время ожидания отображается индикатор загрузки. Изменения через методы composable реактивно обновляют таблицу; группы раскрываются и сворачиваются, нумерация соответствует видимым строкам.

## Запуск

Требуется Node.js 22.12+ или 24+ и npm.

```sh
npm ci
npm run dev
```

## Проверки

Быстрые тесты — `npm test`, браузерные сценарии — `npm run test:e2e`, замеры производительности — `npm run test:performance`.

Подготовка окружения и описание проверок — в [tests/README.md](tests/README.md).
